# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a bypass in the JSON-RPC inspection engine, regex/entropy DLP scanner, or `/proc/<pid>/fd` monitor, please open a GitHub Security Advisory on this repository.
